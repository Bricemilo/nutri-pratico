# Nutri Prático

App de nutrição para iPhone: pacientes, necessidade energética (FAO/OMS 1985 + DRI 2005) e plano alimentar.

- `docs/` — o app instalável (publicado pelo GitHub Pages). Abra no Safari e use **Compartilhar → Adicionar à Tela de Início**.
- `index.html` — a mesma página, em versão para o link do Claude.
- `fonte/` — código-fonte e o script que cruza a TACO com as medidas caseiras da POF/IBGE.

Dados: TACO 4ª ed. (NEPA/UNICAMP, 2011) e Tabela de Medidas Referidas, POF 2008–2009 (IBGE).
